# MatchAI

MatchAI is an intelligent lost-and-found matching system.

## Main Features

- Lost-item report submission
- Found-item report submission
- CNN image feature extraction
- KNN visual similarity matching
- TF-IDF text processing
- Naive Bayes text classification
- Random Forest match prediction
- Fuzzy attribute matching
- Ranked match recommendations
- Admin dashboard

## Technology

- Python 3.11
- Streamlit
- Scikit-learn
- OpenCV
- NumPy
- Pandas
- Pillow
